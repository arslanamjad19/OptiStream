Technical Details:
------------------

Dependencies:
- CMake >= 3.15
- C++17 compiler (GCC 7+, Clang 5+, MSVC 2017+)
- GStreamer >= 1.0 with gstreamer-app
- OpenCV >= 4.0
- ONNX Runtime >= 1.8
- pybind11 >= 2.6 (for Python bindings)
- Python >= 3.7 (for examples)

Build Commands:
  ./build.sh                          # Quick build
  ./build.sh --debug --test           # Debug build with tests
  cmake .. -DONNXRUNTIME_ROOT_PATH=/path/to/onnxruntime
  cmake --build . -j$(nproc)

Usage Examples:
  # C++
  optistream::Pipeline pipeline;
  pipeline.set_callback(callback_fn);
  pipeline.start("videotestsrc", "model.onnx", 640, 480);

  # Python
  import optistream
  pipeline = optistream.Pipeline()
  pipeline.set_callback(callback_fn)
  pipeline.start("videotestsrc", "model.onnx", 640, 480)
